Tipos de contenido

Cada tipo decide su unidad y cuánto aporta a las estadísticas. Lo que se lee —un manwa, una novela— no debería sumar horas de visionado por muchos capítulos que tenga.
Un tipo sin entradas se oculta solo y reaparece al crear la primera; con «Visible» u «Oculto» fuerzas el comportamiento.

Etiquetas

Las etiquetas que representan un tipo (anime, serie, película…) las gestiona la pestaña anterior y aquí salen bloqueadas. El resto son tuyas: puedes renombrarlas o borrarlas.

MyAnimeList

ListIt usa la API oficial de MyAnimeList para buscar y actualizar fichas. Necesita un Client ID propio, gratuito: créalo en myanimelist.net/apiconfig → «Create ID». El Client Secret no hace falta. Se guarda cifrado en este ordenador y nunca sale de él.

—
Sincronización entre ordenadores

Opcional y desactivada por defecto. Guarda tu biblioteca en tu propio proyecto de Firebase para tenerla en varios ordenadores. Nada se comparte con nadie: el proyecto, la cuenta y las claves son tuyos y se guardan cifrados solo en este equipo.
Se sincroniza la biblioteca entera de una vez, así que el último en subir manda. Antes de bajar se hace copia de seguridad local automáticamente.
